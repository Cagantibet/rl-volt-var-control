# IEEE 123-node test feeder (OpenDSS model)

These files are the unmodified OpenDSS model of the IEEE 123-node test feeder, copied from
[dss-extensions/electricdss-tst](https://github.com/dss-extensions/electricdss-tst) at commit
`3b208397160213cae4a9e2d0a7d1aa3528ce26e1`, path `Version8/Distrib/IEEETestCases/123Bus/`.

`IEEELineCodes.DSS` comes from the parent folder (`Version8/Distrib/IEEETestCases/IEEELineCodes.DSS`).
The upstream 123Bus folder only has a one-line stub that redirects to it, so the full file is stored here instead.
